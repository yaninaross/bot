# MOIRAI SHORT Path Feature Extraction & LightGBM Model Training

## Objective

Build a LightGBM regression model that predicts **actual max forward drawdown** (60 minutes, from real market data) using structural features extracted from MOIRAI's 100 sample paths. The model's predicted value becomes the SHORT trading signal — higher predicted drawdown = higher conviction SHORT entry.

## Reuse Existing MOIRAI Paths

The same path files generated by the LONG pipeline batch job can be reused. MOIRAI paths are price forecasts — they don't have a directional bias. We just extract DIFFERENT features from the same 100x60 path matrices.

**No new MOIRAI inference needed.** Use the same `.npy` files from the 89-ticker batch job.

## Target Variable

**`actual_max_drawdown_60m`** — the maximum of `(Close[t] - Low[t+1:t+60]) / Close[t]` computed from real 1-minute OHLCV data. This is **positive** when price drops. A value of 0.05 means the asset dropped 5% from entry within 60 minutes.

```python
# Compute target from master_inference parquet
close_t = df['Close'].values
low = df['Low'].values

for i in range(len(close_t) - 60):
    forward_lows = low[i+1 : i+61]
    max_drawdown = (close_t[i] - forward_lows.min()) / close_t[i]
    actual_max_drawdown_60m[i] = max(max_drawdown, 0.0)  # floor at 0
```

This is NOT from the paths — it's ground truth from the market.

## Feature Extraction Implementation

### Input

Same `.npy` files from the LONG batch job, shape `(100, 60)` — each row is a path, each column is a minute. Values are **prices**. Convert to returns relative to the first bar:

```python
returns[i,t] = (paths[i,t] - paths[i,0]) / paths[i,0]
```

### Per-path derived arrays (compute once, reuse)

```python
per_path_max     = returns.max(axis=1)          # (100,) — adversarial for SHORT
per_path_min     = returns.min(axis=1)          # (100,) — favorable for SHORT
per_path_argmax  = returns.argmax(axis=1)       # (100,) — when does price rally?
per_path_argmin  = returns.argmin(axis=1)       # (100,) — when does price dump?
terminal_returns = returns[:, -1]               # (100,) — where does path end?
```

### Time-to-TP helper (SHORT direction)

```python
def time_to_tp_short(returns, threshold):
    """threshold is NEGATIVE (e.g., -0.02 for 2% drop).
    Returns array of shape (100,) with bar index of first TP hit."""
    hit_mask = returns <= threshold               # (100, 60) bool — price dropped enough
    first_hit = np.argmax(hit_mask, axis=1)       # (100,)
    never_hit = ~hit_mask.any(axis=1)             # (100,) bool
    first_hit[never_hit] = 60                     # convention: never hit = 60
    return first_hit

ttt_2pct = time_to_tp_short(returns, -0.02)
ttt_3pct = time_to_tp_short(returns, -0.03)
ttt_5pct = time_to_tp_short(returns, -0.05)
```

### TP/SL Sequencing helper (SHORT direction)

```python
def pct_tp_before_sl_short(returns, tp_thresh, sl_thresh):
    """tp_thresh is NEGATIVE (price drops), sl_thresh is POSITIVE (price rallies).
    Returns fraction of paths where price drops to tp_thresh before rising to sl_thresh."""
    n_paths = returns.shape[0]
    tp_first_count = 0
    for i in range(n_paths):
        tp_bar = 61  # never
        sl_bar = 61  # never
        for t in range(returns.shape[1]):
            if returns[i, t] <= tp_thresh and tp_bar == 61:
                tp_bar = t
            if returns[i, t] >= sl_thresh and sl_bar == 61:
                sl_bar = t
            if tp_bar < 61 and sl_bar < 61:
                break
        if tp_bar < sl_bar:
            tp_first_count += 1
    return tp_first_count / n_paths
```

### Clustering

Use `sklearn.cluster.KMeans` on `terminal_returns.reshape(-1,1)`. Test k=2,3,4. Pick k with highest `silhouette_score`. If all silhouette scores < 0.3, set `n_clusters=1`.

### Handling NaN/Inf

Clip all features to [-100, 100]. Replace NaN with 0. Replace Inf with the clip bound.

### Output

One CSV per ticker: `{TICKER}_moirai_short_features.csv` with Datetime index + 69 feature columns + `actual_max_drawdown_60m` target column.

Do NOT use May-Jun for LightGBM early stopping. Split within the training window:

| LGB split | Dates | Purpose |

| Train | Mar 1 - Apr 15 | Fit trees |
| Val | Apr 16 - Apr 30 | Early stopping only |

Then retrain on full Mar-Apr with the best iteration count from that val split. This keeps May-Jun completely blind to LightGBM.

### Step 5: LightGBM Model Training

```python
import lightgbm as lgb

feature_cols = [list of 69 features]

# Internal train/val split for early stopping
train_internal = train_df[train_df['date'] <= '2026-04-15']
val_internal   = train_df[train_df['date'] > '2026-04-15']

X_ti = train_internal[feature_cols]
y_ti = train_internal['actual_max_drawdown_60m']
X_vi = val_internal[feature_cols]
y_vi = val_internal['actual_max_drawdown_60m']

model_es = lgb.LGBMRegressor(
    n_estimators=1000,
    max_depth=5,
    num_leaves=31,
    learning_rate=0.05,
    min_child_samples=20,
    subsample=0.8,
    colsample_bytree=0.7,
    reg_alpha=1.0,
    reg_lambda=1.0,
    random_state=42,
    verbose=-1,
)

model_es.fit(
    X_ti, y_ti,
    eval_set=[(X_vi, y_vi)],
    callbacks=[lgb.early_stopping(50), lgb.log_evaluation(50)],
)

best_iter = model_es.best_iteration_
print(f"Best iteration from early stopping: {best_iter}")

# Retrain on full Mar-Apr with the best iteration count
X_train_full = train_df[feature_cols]
y_train_full = train_df['actual_max_drawdown_60m']

model_final = lgb.LGBMRegressor(
    n_estimators=best_iter,
    max_depth=5,
    num_leaves=31,
    learning_rate=0.05,
    min_child_samples=20,
    subsample=0.8,
    colsample_bytree=0.7,
    reg_alpha=1.0,
    reg_lambda=1.0,
    random_state=42,
    verbose=-1,
)

model_final.fit(X_train_full, y_train_full)
```

After running the full investigation, report these three numbers:

1. **May-Jun Spearman r** (predicted vs actual max drawdown, fully out-of-sample)

| Outcome | Action |
|---------|--------|
